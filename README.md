# 🎮 專案名稱：OptiVerse : 光脈域境 / App

OptiVerse 是一款針對光纖通訊領域所設計的數位化教育育成學習應用程式，主要目標族群為初學者及大專院校學生。透過互動式操作模擬、知識點導覽與實驗流程引導，學習者可在無需實體儀器的情況下進行自主學習與技能培養，降低教學門檻並提升學習效率。

在開發初版期間，我進行了超過 10 位受測者的使用者研究與學習成效分析，驗證本應用在光纖通訊基礎技術補充與實驗操作理解上的可行性。結果顯示，本應用有助於強化學習者的知識吸收與實作理解，具有良好的教學輔助潛力。

## 🔧 開發工具與技術

- Unity 版本：`2023.2.10f1`
- 編程語言：C#
- 平台：Android（視你開發的平台調整）
- 版本控制：Git + GitHub

## 📦 專案結構

如 `OptiVerse` 路徑所示。
- Assets/ # All application assets (scripts, scenes, prefabs, materials etc.)
- Packages/ # Unity Package Manager Settings
- ProjectSettings/ # Unity Project Settings
- README.md # This document

## 🚀 如何執行專案

1. 安裝 Unity Hub，並下載對應版本的 Unity。
2. 使用 Unity Hub 開啟本專案資料夾。
3. 點選 `Scenes` > `Login_RegisterPage` > `CN` (預設為中文-繁體) > `HomePage_CN.unity` 開啟主場景。
4. 點選 Play 開始執行。

(*註 : `Login_RegisterPage` 路徑下的 `CN` 為「中文-繁體」場景 ; `EN` 為「英文-美語」場景。*)
